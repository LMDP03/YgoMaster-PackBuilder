# YgoMaster-PackBuilder

A modular tool for importing, validating, and building custom YGOPRODeck packs for YgoMaster.

## Goals

The project aims to:

- import custom packs from YGOPRODeck;
- map YDK card IDs to Master Duel internal IDs;
- normalize and validate custom rarity distributions;
- generate YgoMaster-compatible shop and pack configurations;
- support personal main packs, targeted mini-packs, and shared staple packs;
- keep generated content separate from the upstream YgoMaster repository.

## Status

Early design and architecture phase.
